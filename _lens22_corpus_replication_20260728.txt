第22レンズ「コーパスを変えた再現性」 2026-07-28 (第27回続50)
  — 第6レンズの結論は、コーパスを変えても再現するか —
================================================================================

■ なぜこのレンズが新しいか

第6レンズは「実文コーパスの延べトークン被覆」を測り、
  『CSV2890層は辞書の約5%しか占めないのに実文トークンの53.2%を占める』
という優先順位の直接証明を得た。これは全21レンズの中でも最も強い結果の一つだった。

しかしそれは **1つのコーパスでの1回の測定** であり、再現性は検証していない。
再現しなければ、あの53.2%はそのコーパス固有の性質だったことになる。
第21レンズが「対照群」を導入したのに続き、本レンズは「再現」を導入する。

■ 使ったコーパス（どちらも辞書とは独立）

  コーパスA = **ユーザー自身が書いたエスペラント原文**
              (随想4本＋日記21日分。`漢字化エスペラント日記/…原文エスペラント集成`)
              総語数 8,166 / 辞書照合できた語 97.1%
              → 実際の使用場面そのもの。辞書の見出し語選定とは無関係

  コーパスB = **PIV2020 の用例文**（`_斜体_` で示された例文を全抽出）
              総語数 436,412 / 辞書照合できた語 95.3%
              → 辞書編纂者が「典型的用法」として選んだ文

  文体も出自も規模も全く違う（個人の日記 8千語 ⇔ 辞書の用例文 44万語＝**53倍差**）。
  両方で同じ順序が出れば再現性は強い。

■ 測った量（第6レンズと同じ）

  (1) 辞書シェア … その層の語根が辞書全体の語根種類数の何%か
  (2) 実文シェア … その層の形態素が実文の延べ内容トークンの何%か
  (3) ★てこ比 = (2)/(1) … 語根1種あたりの実文での働き

--------------------------------------------------------------------------------
■ 結果: 両コーパスで完全に再現した
--------------------------------------------------------------------------------

  辞書シェア（分母）: 機能形態素 1.3% / CSV2890 14.8% / PEJVO 44.3% / PIV 35.3%

  ── コーパスA（ユーザー原文の日記・随想）──
  層                実文シェア   辞書シェア    ★てこ比   漢字化率
  機能形態素            49.3%      1.3%    39.07倍   100.0%
  CSV2890            47.7%     14.8%     3.22倍    89.6%
  PEJVO               2.8%     44.3%     0.06倍    60.2%
  PIV                 0.2%     35.3%     0.01倍    28.6%
    最優先層(機能形態素+CSV2890)合計 = 実文 96.9% / 辞書 16.1% → てこ比 6.03倍
    実文の内容形態素が漢字で描画される率 = 93.7%

  ── コーパスB（PIV用例文）──
  層                実文シェア   辞書シェア    ★てこ比   漢字化率
  機能形態素            39.1%      1.3%    30.99倍    99.9%
  CSV2890            52.7%     14.8%     3.56倍    85.1%
  PEJVO               6.6%     44.3%     0.15倍    80.3%
  PIV                 1.4%     35.3%     0.04倍    56.9%
    最優先層合計 = 実文 91.8% / 辞書 16.1% → てこ比 5.71倍
    実文の内容形態素が漢字で描画される率 = 90.1%

  ★**てこ比の順序が両コーパスで完全に一致し、単調である**:
      機能形態素(31〜39倍) ≫ CSV2890(3.2〜3.6倍) > PEJVO(0.06〜0.15倍) > PIV(0.01〜0.04倍)

  ★**第6レンズの 53.2% を直接再現した**: CSV2890単独の実文シェアは 47.7%(A) / 52.7%(B)。
    別のコーパス・別の抽出方法で同じ帯域に落ちた。あの数字はコーパス固有ではなかった。

  ★**PIV層は辞書の 35.3% を占めるのに、実文では 0.2〜1.4%**（25〜175分の1）。
    第3優先に置く理由が、辞書の外の実文で裏付けられた。

  ★**ユーザー自身の日記では、最優先層が内容形態素の 96.9% を占める。**
    最優先層さえ覚えれば、実際に書かれている文章はほぼ全部読める。

  ★漢字化率も層別に単調（A: 100.0/89.6/60.2/28.6 ・ B: 99.9/85.1/80.3/56.9）。
    実文で出会う内容形態素の9割が漢字で描画される。

■ 頑健性: 照合器を3回直したが、結論は動かなかった
--------------------------------------------------------------------------------

  自分の照合器のバグを2つ見つけて直した。どちらも**最優先層を過少評価する向き**だった。

  ① 見出し語を語幹に落とすと機能語が消える
     相関詞 kiu→ki・前置詞 en→(空) となり、kiuj/tiuj/kiun 等が全滅していた。
     → 裸形そのものもキーに加えた。
  ② ENDINGS に副詞+対格の融合形 'en' が入っていたため、
     **前置詞 en(=内) を語尾と誤判定して丸ごと落としていた**（PIV例文で6,851回＝全語の1.6%）。
     → 1分節だけの見出しで接尾辞見出し(-で始まる)でないものは実在語として扱うようにした。

  照合率 94.6%→95.0%→**97.1%**(A) / 93.1%→93.7%→**95.3%**(B) と改善したが、
  CSV2890の実文シェアは A 48.7→48.6→47.7 / B 54.0→53.5→52.7 と 1pt 以内で安定し、
  **てこ比の順序は3版とも同一**だった。結論は照合器の精度に依存していない。

  残る未照合（A 2.9% / B 4.7%）は固有名(§7)・英語・新造複合語(kanjiigo・noktobuso 等)が主で、
  層に系統的な偏りは無い。

■ 結論
--------------------------------------------------------------------------------

  ・優先順位の効果は **コーパスを変えても再現する**。てこ比の順序は
    文体も規模も全く違う2コーパスで完全に一致し、単調だった。
  ・第6レンズの中心的な数字(CSV2890の実文シェア53.2%)は、独立なコーパスで再現された。
  ・PIV層は辞書の3分の1を占めながら実文では1%前後しか現れない＝第3優先は妥当。
  ・ユーザー自身の文章では最優先層が内容形態素の96.9%を占め、漢字化率は93.7%。
