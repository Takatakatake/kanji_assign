■ なぜこのレンズが新しいか

第1〜20レンズは全て【実際の状態】だけを測ってきた。被覆・構造・裸字率・語完読・
実文token・学習ROI・識別子勾配・一意性・棚卸し・学習順序・版間整合・配信面・
多義裁定・逆引き・訳語接地・語義被覆・履歴安定性・合成語の接地——
どれも「単調である」「健全である」という所見は出せた。

しかし **その優先順位が実際にどれだけ得をさせたのか** は一度も測っていない。
対照群が無いからである。「単調だ」は「価値がある」と同義ではない。

本レンズは同じ漢字割り当てのまま、**学習者が語根を覚える順序だけを差し替えて**
成果曲線を比べる。順序は方針書§13 作業フロー step2 を忠実に再現した:

  ①実際の優先順位   機能語・接辞 → CSV2890(Unified_Level昇順) → PEJVO(行順) → PIV(行順)
  ②頻度貪欲         F降順(派生語を多く持つ語根から。素朴だが強力な代替案)
  ③逆順             PIV → PEJVO → CSV2890(優先順位を反転した最悪ケース)
  ④無作為           決定論的シャッフル(再現性のため乱数不使用)
  ⑤層順のみ         層の順序は①と同じ・層内は無作為 ← ★Unified_Levelの寄与を切り出す
  ⑥層順+層内F降順   層の順序は①と同じ・層内はF降順   ← ★難易度指標 vs 頻度

成果指標は2つ。どちらも「語が完全に漢字で読めるか(完読)」で測る:
  (A) CSV2890語 2,832語の完読率 … 優先順位が『何のためか』を直接測る
  (B) 全辞書語 52,079語の完読率 … 広がり

★循環への注意: F は辞書内の派生語数なので、②頻度貪欲は(B)に対して**貪欲最適そのもの**。
  (B)で②が勝つのは構造的に当然で、意味があるのは(A)でどちらが勝つかである。
  (A)のCSV2890メンバーシップはユーザー提供の外部CSV由来でFから独立している。

■ ★訂正 (2026-07-28 続49・別AI監査の指摘が正しかった)
--------------------------------------------------------------------------------

  初版は「完読」の判定に **need(漢字描画された形態素)** だけを使い、
  **ラテンのまま残る内容形態素を持つ語まで完読に算入**していた。
  そのため曲線が 100% に到達する見かけの上限が出ていた。

  正しくは、ラテン残りのある語はどの順序でも永久に完読できないので分子から外す。
  **真の天井 = CSV2890語 2,831/2,832 = 99.96%(表示100.0%) / 全辞書語 50,044/52,079 = 96.1%**
  唯一のCSV2890例外は pro/cent/o⟦pro/百/o⟧。

  ★**順序間の比較は同じ母集団に対して行うので、結論は変わらない**:
      到達語根数    50%    80%    90%
        ①実際     1,388  2,186  2,465
        ②頻度貪欲  1,513  3,075  4,266   (①は 889・1,801語根 少ない=29%・42%節約)
        ③逆順     7,409  8,241  8,526   (①は 6,061語根 少ない=71%節約)
        ④無作為    4,488  7,103  7,918   (①は 5,453語根 少ない=69%節約)
        ⑤層内無作為 1,415  2,218  2,486   (差は 21〜32語根=1〜2%のみ)
      面積差: vs② CSV2890 +7.0pt / 全語 −6.5pt   vs③ +68.6/+49.7   vs④ +34.8/+31.7
              vs⑤ +0.2/+3.0   vs⑥ −0.0/−4.2
      (A)で①が②を逆転する語根数 = 800(以降ずっと上)。K≤700 は②が僅差で上。

  下記本文の(B)の表は初版の値(天井100%)なので、上の訂正値を正とする。
  スクリプト `_lens21_counterfactual_order.py` は修正済み(pure フィルタを追加)。

  ★教訓: 「完読」のような複合条件の指標は、**分子の定義を実データで検算する**こと。
    ラテン残りの割合(全語で3.9%)を先に測っていれば天井の異常に気づけた。

■ ★訂正2 (2026-07-29・別AI監査の指摘が正しかった)
--------------------------------------------------------------------------------

  指摘: 『⟦…⟧が全く無い行を分母から除外した上で「全辞書の天井96.1%」としている。
        全辞書そのものを測った値ではない』

  ★正しい。実測すると:
      見出し行 総数            62,111
      ⟦⟧を1つでも持つ行        52,234
      本レンズの分母(B)        52,079  ← ⟦⟧ありのうち内容形態素が取れた行
      除外されていた行         10,032  (62,111 − 52,079)

    除外分は §7 固有名や未対応語根で、**全体がラテンのまま**の見出しである。
    どの順序を採っても永久に漢字では完読できないので、順序比較の分母としては
    外すのが妥当だが、**「全辞書語」という呼び方が不正確だった**。

  ★正しい呼び方と数値:
      「漢字が1つでも付いた語」を分母にした天井 = 50,044 / 52,079 = **96.1%**
      「全見出し語」を分母にした天井           = 50,044 / 62,111 = **80.6%**

  ★**順序間の比較は6順序すべてが同一の分母を共有するので、結論は一切変わらない**
    (節約語根数・逆転点・面積差はすべて不変)。変わるのは天井の呼称だけである。

  ★教訓: 続49 の訂正は分子(pure フィルタ)の誤りだった。今回は分母の呼称。
    **同じ指標で分子と分母の両方を実データで検算する**こと。

■ 主要結果 ②: 正直に報告すべき劣位 — 広がりでは頻度貪欲に負ける
--------------------------------------------------------------------------------

  全辞書語 52,079語の完読率

  覚えた語根数        500   1000   2000   3000   5000   8000
  ①実際の優先順位   15.6%  32.5%  54.3%  67.3%  80.7%  96.1%
  ②頻度貪欲        23.8%  41.6%  63.6%  76.3%  89.4%  98.1%   ← ②が勝つ

  全予算にわたる平均で **①は②に 6.8pt 負けている**。これは隠さず報告する。
  ただし前述のとおり ② は(B)の**貪欲最適**であり、①が負けること自体は設計どおりである。
  問題は「どれだけ負けているか」で、実測は次のとおり:

  ★決定的な数字:
    **K=2,800語根で①は最優先層を100%完読可能にする。その時点で広がりも貪欲最適の89%を確保。**
    同じK=2,800で②の最優先層完読率は **76.7%** にとどまる。

    つまり②を採ることは「最優先層の約1/4を読めないまま放置して、広がりを11%上乗せする」
    取引である。ユーザーの優先順位はその取引を明示的に拒否している＝**設計意図どおり**。

  ★唯一の劣位区間(開示): K≤700 では(A)でも②が僅差で上(500語根時点 17.2% vs 16.7%)。
    K=800 以降は①が逆転し、以後ずっと上回る。ごく初期だけ頻度貪欲が有利。

■ ★訂正3 (2026-07-30 第24レンズ・この結論は指標依存だった)
--------------------------------------------------------------------------------

  下の主要結果③「層内順序(Unified_Level昇順)を無作為に壊しても +0.2pt しか変わらない」は
  **完読率という尺度に限った話**であることが第24レンズで判明した。

  同じ順序・同じデータで2つの指標を計算すると(_lens24b_reconcile.py):
    完読率      ①Unified昇順 vs ②層内無作為  K=100 +0.0pt / K=500 **-0.5pt**  ← 本レンズの量
    token被覆   ①Unified昇順 vs ②層内無作為  K=100 +10.3pt / K=500 **+47.5pt**

  完読は語の **最も稀な形態素** に律速されるので順序に鈍感、
  token被覆は **最も頻出の形態素** が支配するので順序に敏感、という違いによる。

  ★したがって「層内順序はほとんど寄与しない」は完読率については正しいままだが、
    **学習者が日々経験する『読める文字の割合』では層内順序が最大47ptを動かしている**。
    『Unified_Level に多少の誤差があっても効果は失われない』という堅牢性の読みも、
    完読率に限れば正しいが token被覆には当てはまらない。

--------------------------------------------------------------------------------
■ 主要結果 ③: 価値の源泉は「層の順序」であって「層内の並べ方」ではない
--------------------------------------------------------------------------------

  ①実際 と ⑤層順のみ(層内を無作為に壊したもの) の差:

    平均優位          CSV2890完読率 +0.2pt / 全語完読率 +3.1pt
    到達語根数の差    50%到達 −27 / 80%到達 −32 / 90%到達 −21 語根(いずれも1〜2%)

  ⑥層順+層内F降順 との差はさらに小さい(CSV2890完読率 −0.0pt = ほぼ同点)。

  ★つまり **Unified_Level 昇順という層内の細かい並べ方は、成果にほとんど寄与していない。**
    効いているのは「**どの2,890語を最優先層と定義するか**」というメンバーシップの方である。

  これは方針の弱点ではなく、**堅牢性の証拠**として読むべきである:
    層内の順序が多少ぶれても成果は変わらない＝
    運用が難易度数値指標の細かい精度に過度に依存していない。
    逆に言えば、Unified_Level に多少の誤差があっても優先順位の効果は失われない。

■ 結論
--------------------------------------------------------------------------------

  ・優先順位は無作為に対して **90%到達で5,453語根(69%)の節約**、
    逆順に対して 6,062語根(71%)の節約を生んでいる。効果は実在し、大きい。
  ・最も手強い代替案(頻度貪欲)に対しても、最優先層では 889〜1,801語根(29〜42%)速い。
    広がりでは6.8pt負けるが、これは貪欲最適に対する差であり、
    最優先層100%達成時点でも貪欲の89%を確保している＝取引として妥当。
  ・価値は層の順序が生んでおり、層内順序は1〜2%しか動かさない＝堅牢。
  ・K≤700 で頻度貪欲が僅差で上回る区間があることは開示する。
