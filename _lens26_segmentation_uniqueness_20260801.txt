■ なぜこのレンズが新しいか

読字の連鎖は 文字列→トークン→語根→意味。トークン→語根(第16=逆引き99.7%一意)・
語根→意味(第17/18=接地)・語面どうしの混同(第23=近傍衝突)は測定済みだが、
最初の一段は未測定だった。配信面に形態素境界は無い(第23で確定)。読者は 化学o を
[化学]o と読むのか [化][学]o と読むのか——分節が曖昧なら以降の全保証が崩れる。
第25レンズの批判[C5](学⊂化学の包含対6,886)が積み残した問いでもある。

■ 設計(3点)

1) 比較測定: 同じ語を2表記系で同じDPパーサにかける。
   B=素のエスペラント(raw綴り連結×rawトークン表) / K=漢字化配信形(⟦⟧連結×描画トークン表)。
   ラテン固有の再分節曖昧性(amas→am·as/a·mas)は両側で相殺され、K>B だけが漢字化の持ち込み分。
2) CJK署名: 読者が実際に直面する選択は【CJK含みトークンの切り方】。混成トークン
   (何u/那o/kuri疗=相関詞含む521種)は丸ごと1トークン、ラテンのみ区間はギャップ。
3) 復号重大度: 曖昧語の各解析を token→raw 対応で復号し比較。
   S0=全解析が同一語に復号 / S1=代替は非語(語彙が自己修正) /
   S2syn=代替は同義語(語釈相互参照で機械判定) / S2adj=それ以外(要精査)。

■ 検証プロセス(ultracode: Workflow 5エージェント並列の敵対的検証)

パーサDP・データ構築のバグ狩り2・見出し主張の反証2・設計批判1。
【確定した正しさ】DPは独立定式化との全数照合(実データ14,317語+合成7,952例)で不一致0。
K>B=0 は CAP撤廃の厳密再計算(bigint)でも両版0件。表面同形censusは独立実装と完全一致(78/150群)。
【是正した測定バグ】v1→v5で7件: ラテン語尾アーティファクト(是as→是·a·s を曖昧と数えていた)・
混成トークン破壊(相関詞 那o/何u をOOV化=5.14%の偽解析不能)・ハイフン連結(1語過大)・
CSV接辞のハイフン正規化漏れ(98語が層誤帰属)・attestedに屈折形が無くS2過小(+11件)・
コーパスのメタデータ夾雑(OOV154件の79%)・「全件」見出しで実は[:30]/[:25]打ち切り
(非公開側に 同性o=sameco/gejo 等の危険対が隠れていた)。

■ 結果①: 漢字化は分節曖昧性を一切増やしていない(K>B=0/68,675語×両版)
--------------------------------------------------------------------------------

    層          素エス一意(B=1)   漢字化一意(K=1)   悪化(K>B)   改善(K<B)
    CSV2890        2.4%             91.3%           0        95.8%
    全体(学習者版)     2.4%             73.6%           0        95.9%
    全体(学術版)      3.1%             71.7%           0        95.1%

  ★同一パーサ・同一粒度の比較で、漢字化が解析数を増やした語は両版とも0件。95%超で改善。
  ・限定(独立検証の指摘): この言明は語彙表の定義に相対的。Bを「実在語のみの語彙表」B'に
    変えると K>B' が学習者版1.2%発生する。また解析数はホモグラフ融合(下記③)を測れない。
  ・B=1が2.4%しかないのは形態素表で刻む機械値であり人間の曖昧性ではない(誤読注意)。

■ 結果②: CJK署名一意性 90.8%(学習者版)。曖昧の実害はごく薄い層に限られる
--------------------------------------------------------------------------------

    学習者版: 署名一意 90.80% / 曖昧 6,316件(延べ9.2%)
      重大度: S0=112 / S1=6,018(95%) / S2syn=94 / ★S2adj=92延べ(80対)
    学術版:   署名一意 88.22% / 曖昧 8,091件 / S2adj=154延べ
    実配信テキスト(メタデータ除外後7,429トークン): 一意 98.13% / 曖昧 1.43% / 解析不能 0.44%

  ★曖昧の95%はS1=代替解析が語として存在しない(四月o→四·月·o は「kvarmonato?」で非語)。
  ★S2adjの実態も大半は同概念対(气管=trakeo・多角=poligono・斜边=klinrando=同一物の
    複合語形と借用語形=意味系の設計どおり)。全80対は _lens26_s2_full.tsv に全件掲載。
  ★層間差(CSV2890 4.2% vs PEJVO 9.3%)は品質差ではなく構造差(2字熟語トークン保有率
    33.7% vs 46.5%)。同一構造セルでは逆転し(PEJVO 0.32%≦CSV 0.47%)、
    実在別語誤読率(S2adj)は 0.137/0.122/0.113% と層間でほぼ等値=優先層の被害はない。
  ・開示(独立検証の指摘): これらは語彙完備の理想読者に対する量。CSV2890層だけ知る部分
    語彙読者では「一意だが誤分節」2,180語という本レンズに見えないクラスが生じる(ただし
    CSV2890層自身の語はむしろ改善4.52→3.56%=優先層の設計は部分語彙でも機能)。
    実配信96.6→98.1%は作成者自身のテキスト=生成器と検証器が同一で上限側バイアス。

■ 結果④: 逆変換アプリへの影響(検証エージェントの調査)と 全a/全o/无o の裁定案

  kanjized-esperanto-reverter は貪欲最長一致のみで文脈規則・衝突台帳を持たず、

  → _lens26_surface_homographs.tsv(census台帳)をアプリ連携用の成果物として提供可能。

  ★全a/全o/无o の裁定案 = 据置(現状維持)を推奨:
    - 両側とも tier0(相関詞は最頻語・integr/sen も CSV2890)で、どちらへの識別子付与も
      高頻度語の churn(第19レンズ: 一度覚えた字が変わるのは最悪)。
    - 意味は隣接(全=すべて/整全、无=無/なしで)、文脈での誤読実害は薄い。
    - 実配信での遭遇は 全o×1/全u系×数件のみ。逆変換の一意性はアプリ側台帳で救う。

■ 結論
--------------------------------------------------------------------------------

  ・漢字化は素のエスペラントに対し分節曖昧性を1語も増やしていない(K>B=0、厳密再計算で確定)。
    連結母音の保持(§設計)と識別子・混成トークン設計が、境界の無い配信面でも
    90.8%(理想読者・型基準)/98.1%(実配信)の一意分節を成立させている。
  ・曖昧の95%は語彙が自己修正するS1。実在別語対80対の大半は同概念の複合語形/借用語形。
    実在別語誤読率は層間等値=優先順位の上位層に被害は無い。
  ・[J]監査のキー設計欠陥(粒度差の表面同形が不可視)を同定し、表面キー第2パス+台帳228面
    +退行試験で恒久化した。真に新規の表面同形は相関詞融合型3群(全a/全o/无o)=据置を推奨。
  ・是正: 0件(データ変更なし)。機構追加: [J]第2パス。角を矯めた箇所: なし。
  ★本レンズ自身の初版も測定バグ7件を5方向の独立検証で是正した(第21〜25に続く6例目)。
    「新発見」の過大主張も反証エージェントに削られた(73/78は第23レンズ既出)。
