第23レンズ「近傍衝突 — 最重要語ほど見分けやすいか」 2026-07-28 (第27回続51)
  — 初めて「読めるか」ではなく「取り違えないか」を測る —
================================================================================

■ なぜこのレンズが新しいか

第1〜22レンズは全て **読めるか** を測ってきた。被覆・完読・接地・実文シェア・
学習ROI・再現性——どれも「その語が漢字で読めるようになるか」の系列である。

しかし読字の失敗様式は2つある。読めないことと、**読めるが別の語と取り違えること**。
第9レンズ「一意性」は語根→漢字の割り当てが一意かを見たが、
**出来上がった語の描画面どうしがどれだけ近いか** は一度も測っていない。

優先順位との関係はこうである:
  優先順位が「順序」だけでなく「質」にも効いているなら、
  **最重要語ほどよく分離されている** はずである。
  最優先層に混同対が集中しているなら、優先順位は割り当ての順番には効いていても
  出来上がりの品質には効いていないことになる。

■ 測り方

測る単位 = **内容形態素列(レキシーム)**。abism/a と abism/o は同一レキシーム。
語尾(o/a/e/i/as…)は全語共通で識別に寄与しないので面から外す
(語尾を含めれば衝突は減るので、本レンズの評価は保守側)。

CJKの読み面に即した3つの混同類型で測る:

  類型1 完全衝突   漢字列が完全に一致する別レキシーム。
                   識別子(ᴬ ᵀ ˢ…)で解決済みか否かを分け、未解決分をさらに
                   **同義(害が無い)** と **異義(真の曖昧)** に分ける。
                   同義対(fontano/s^prucfonto→喷泉)を欠陥に数えると誤警報になる
  類型2 転置衝突   同じ文字の集合で並びだけ違う(小脑/脑小型)。CJKでは実際に混同される
  類型3 高重複近傍 1字違いで長さ3以上(=2/3以上を共有)

  ★2字面どうしの1字違い(共有率50%)は危険に数えない。電车/电话 を混同する読者はいない。
    数えると 240万対に膨らむが実質を反映しない。

対照群を2つ置く(第21レンズの方法論を継承):
  対照A = 同じ語集合の **ラテン綴り面**(漢字化前の状態)
  対照B = 形態素→漢字列の割り当てを **長さ保存で無作為に入れ替えた面**(5回平均)
          実際の割り当てが偶然より良いか悪いかを測る

--------------------------------------------------------------------------------
■ 自分の分析器のバグを3つ見つけて直した(いずれも危険を過大評価する向き)
--------------------------------------------------------------------------------

 ① 識別子を1文字として編集距離に数えていた
    「厌ᴬ ⇔ 订ᴬ」のような、共有しているのが識別子だけの対を近傍と誤判定していた。
    識別子は内容文字ではなく曖昧性解消の付加情報なので、距離は識別子を外した
    漢字列の上で測り、識別子は属性として扱うのが正しい。
 ② 語尾を「集合として全位置から」剥がしていた
    en/ig/i の en(内)・an/ar/o の an(員)・ajn/ist/o の ajn が語尾と誤判定されて消え、
    「enigi と -ig- がどちらも 使 で衝突」のような偽の衝突を量産していた。
    語尾は語末にしか現れないので末尾からのみ剥がす。
    さらに **an/en/on は剥がす集合から外した**。接尾辞 -an-(員)・-on-(分数)・
    前置詞 en(内) と同綴りで、含めると met/an/o(甲=メタン)が met(置)と同一視され
    「meti と kirasi がどちらも 甲」という偽の衝突が出る。
    (第22レンズで前置詞 en を落としていたのと同じ種類の誤り。同じ罠に2度かかった)
 ③ 「恣意的」の判定を形態素一致だけで行っていた
    偽分解(未分解)の見出しを取りこぼす。imperialismo は1分節のまま 帝主义 と
    描かれるので、femin/ism/o と 主义 を共有していても恣意的と誤分類されていた。
    decembro/novembro(十二月/十一月)も同様。
    → ラテン綴りどうしが4文字以上の共通部分文字列を持てば系統的に分類する。

  修正の効果: 「異義の完全衝突」は 107対→48対、「恣意的な転置」は 94対→53対、
  「恣意的な高重複」は 2,418対→1,150対 に縮んだ。**過大評価を全て除いた上での結果が以下**。

--------------------------------------------------------------------------------
■ 主要結果 ①: 最優先層は「短い面」で構造的に守られている
--------------------------------------------------------------------------------

  層           レキシーム   平均字数    1字     2字     3字   4字以上
  CSV2890        2,692     1.10   91.0%   8.4%   0.5%    0.0%
  PEJVO         21,891     2.16   11.3%  64.5%  21.5%    2.8%
  PIV            8,835     2.15   19.6%  50.6%  25.5%    4.3%

  ★**最優先層の 91.0% が1字面**であり、平均字数は下位層のちょうど半分である。
    これは自然言語の書記体系が持つ性質そのものである(最頻語ほど短い形を得る)。

  そして1字面は **転置衝突も高重複近傍も構造的に起こり得ない**。
  最優先層の保護は「混み合った空間で上手に離した」結果ではなく、
  **そもそも短い面をもらえたこと自体** から来ている。
  優先順位が字の配分に効いていることの、最も直接的な現れである。

--------------------------------------------------------------------------------
■ 主要結果 ②: 識別子層が曖昧性の 97% を消している
--------------------------------------------------------------------------------

  漢字列だけで見ると、全レキシーム 33,418 件のうち **10,191 件(30.5%)** が
  他のレキシームと同一の面を持つ。3語に1語が曖昧ということになる。

  識別子を付けた正式な面では、これが **320 件(0.96%)** まで落ちる。
  対の数では 157,316 対 → 166 対(99.9%解消)。

  ★識別子層は装飾ではなく、この書記体系を成立させている中核である。
    これを外すと3語に1語が曖昧になる。

  残る166対の内訳:
    同義で無害         118対  (内訳: 同一形態素の別見出し86 / 相互参照23 / 訳語重複9)
    異義の可能性        48対  ← 全件を目視。下記のとおり是正対象は無し

  ★既存の検証 [J] との突き合わせ(単位が違うので両方正しい):
    [J] は **語尾まで含めた見出し語そのもの** の完全一致を見ており、真の同形異義は
    学習者版6種・学術版4種・★新規0。本レンズは **語尾を外した語幹(レキシーム)** で
    測っているので、o/a/i の違いで区別される対まで衝突に数える＝より厳しい側の指標。
    48 と 6 の差は「語幹だけ見ると同じだが実際の面では語尾で分かれる」対であり、
    実運用の曖昧性は [J] の6種、本レンズの48は上限値として読むのが正しい。

■ 主要結果 ③: 危険度は優先順位どおりに単調
--------------------------------------------------------------------------------

  層別の危険度(その層のレキシーム全件を分母に。1字面が構造的に安全であること自体が
  保護なので、分母から外さず一緒に数えるのが正しい)

  層           全件      異義の完全衝突    恣意的な転置    恣意的な高重複
  CSV2890     2,692     4 (0.15%)     1 (0.04%)     5 (0.19%)
  PEJVO      21,891    59 (0.27%)    85 (0.39%)   428 (1.96%)
  PIV         8,835    33 (0.37%)    11 (0.12%)   218 (2.47%)

  ★異義の完全衝突は 0.15% < 0.27% < 0.37% と **優先順位どおりに単調**。
  ★恣意的な高重複は 0.19% < 1.96% < 2.47% と単調で、**最優先層と PIV で13倍の差**。
  ★恣意的な転置も最優先層が最小(0.04%)。

  つまり「最重要語ほど混同されにくい」は実測で成り立っている。

  ・開示すべき非単調: 転置は PEJVO(0.39%) > PIV(0.12%) で第2層と第3層が逆転する。
    PIV の方が1字面(19.6%)と4字以上(4.3%)の両端が厚く、転置が起こりやすい
    2字面の割合が薄い(50.6% vs 64.5%)ことによる分布の差である。
  ・開示すべき小標本: 漢字2字以上に絞った条件付き率で見ると
    CSV2890 は 242件しか無く(層の9%)、条件付き高重複率は 2.07% で
    PEJVO 2.20% とほぼ差が無い。つまり **効果のほぼ全部が「面の短さ」を経由している**。
    2字以上の語だけを比べれば最優先層が特別に守られているわけではない。

■ 対照群
--------------------------------------------------------------------------------

  【対照A】同じ語集合のラテン綴り面(漢字化前)
    完全衝突 10対 / 転置衝突 1,074対 / 高重複近傍 8,062対
    漢字面は平均2.3字、ラテン面は平均8.2字。面が短いほど衝突しやすいのは構造的で、
    この対照は「漢字化が衝突を増やすか」(増やすに決まっている)ではなく
    **増えた分が識別子で処理されているか** を見るためのものである。
    → 増えた 157,306対 のうち未解決は 166対 = 0.1%。処理されている。

  【対照B】形態素→漢字列を長さ保存で無作為に入れ替えた面(5回平均)
                    実際      無作為     比
      完全衝突     157,316   168,025   0.94倍
      恣意的な転置      53     3,915   **0.01倍**
      恣意的な高重複  1,150     2,083   0.55倍

    ★恣意的な転置が偶然の **74分の1** しか無いのが最も強い所見である。
      意味に基づいて字を割り当てているため、別々の語が同じ文字集合を持つことが
      ほとんど起きない。無作為割り当てなら3,915対発生する。
    ★完全衝突が 0.94倍(ほぼ偶然並み)なのは想定どおり。完全衝突の総数は
      「どの字をどの形態素に当てたか」ではなく「字の在庫がいくつあるか」で決まる。
      だからこそ識別子層が要る。

■ 最優先層に関わる混同対 4件 — 全件を個別に判定した
--------------------------------------------------------------------------------

  ① adiau^ ⇔ revidi 【再见】
     adiaŭ=さようなら / revidi=再会する。中国語の 再见 はまさに「また会う」であり、
     両語に同じ面が立つのは **意味的に正しい**。むしろ理想的な一致。→ 是正不要

  ② mezo ⇔ mesoo 【中】
     mezo=中央(CSV2890) / mesoo=腸間膜のひだ(PIV)。解剖学接頭辞 meso- は「中間の」の意で、
     中 はどちらにも意味的に正しい。PIV側は極めて稀。→ 是正不要

  ③ neniam ⇔ sentempa 【无时】
     neniam = neni(无)+am(时) / sentempa = sen(无)+temp(时)。
     どちらも構成どおりの描画であり、衝突は **固定形態素描画から必然的に生じる**。
     解消するには无か时の固定描画を壊すしかなく、それは中核不変条件の破壊にあたる。
     → 是正不要(角を矯めて牛を殺す典型例)

  ④ si ⇔ heks 【己】
     si=自分(CSV2890) / heks/=6炭素鎖を示す化学接頭辞(PIV)。
     己 は天干の第6位であり、heks/an/o→己烷 は **実際の中国語の化学命名法そのもの**。
     しかも中国語自身が 己(おのれ)と 己(第6位)を同形で使っている。
     漢字圏の慣行に忠実な結果であって欠陥ではない。→ 是正不要
     (なお一般の「六」の意味では heks は 六ᴴ に描かれ、化学接頭辞のときだけ 己 になる。
      文脈別描画の inline rule が正しく効いている)

  高重複近傍で最優先層に関わるものも、decembro/novembro(十二月/十一月)、
  feminismo/imperialismo(女ᶠᴱ主义/帝主义)、karoto/g^ardenrapo(胡萝卜/园萝卜ᴿᴾ)のように
  **1字違いであること自体が体系の透明性の現れ**である対ばかりだった。
  中国語で 十一月 と 十二月 が1字違いなのと同じことで、これは長所である。

--------------------------------------------------------------------------------
■ 副産物: 転置衝突の主因が分かった
--------------------------------------------------------------------------------

  恣意的な転置53対を見ると、大半が **エスペラントの接尾辞後置 vs 中国語の修飾語前置**
  という語順差から来ている。

    cerbeto 脑小 ⇔ cerebelo 小脑   (どちらも小脳)
    langeto 舌小 ⇔ uvula 小舌     (どちらも口蓋垂)
    arkipelago 群岛 ⇔ insularo 岛群 (どちらも群島)
    jarmilo 年千 ⇔ milenio 千年    (どちらも千年紀)
    geodezio 测地 ⇔ termezuri 地测  (どちらも測地)

  ★注目すべきは、これらが **意味の異なる2語ではなく、同義語の2通りの描画** である点。
    取り違えても意味は変わらないので実害は小さい。
  ★是正しようとすると分解鏡像(成分固定字の連結)を壊すことになる。
    jarmilo は jar(年)+mil(千) だから 年千 なのであって、これを 千年 に直すことは
    固定形態素描画の放棄を意味する。→ 是正しない。

  一方、意味が本当に違う転置(jamba 抑扬 ⇔ trokea 扬抑)は、
  中国語の詩学が実際に 抑扬格/扬抑格 と呼び分けているとおりであり、**正しい**。

■ 結論
--------------------------------------------------------------------------------

  ・最優先層は「混み合った空間で上手に離された」のではなく、**91.0%が1字面という
    短さ自体によって構造的に守られている**。優先順位が字の配分に効いている直接証拠。
  ・危険度は優先順位どおりに単調(異義の完全衝突 0.15/0.27/0.37%、
    恣意的な高重複 0.19/1.96/2.47% = 最優先層とPIVで13倍差)。
  ・識別子層は曖昧レキシームを 30.5% → 0.96% に落としている。中核機構である。
  ・恣意的な転置は偶然の74分の1。意味に基づく割り当ての帰結。
  ・最優先層に関わる混同4件は全て意味的に正しいか、固定形態素描画から必然的に
    生じるもので、是正すべきものは無かった。

  是正: 0件。データ変更: 0件(読み取りのみ)。角を矯めた箇所: なし。
