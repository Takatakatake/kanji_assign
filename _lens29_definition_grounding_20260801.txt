■ 何を測ったか / なぜこの領域が空白だったか

  第17レンズ(訳語グラウンディング)は、外部真値との照合で最優先層の接地率93.1%(偶然0.7%
  =lift 133倍)を出した一方、報告書 L53 で明記している:
    「★PIV層(tier2)は 3154語根中 3099(98.3%)が【測定不能】。PIV項目の語釈はエスペラント文で
      日本語訳も中国語訳も無く、外部照合の手段が原理的に存在しない」
  第20レンズも同じ理由でPIV層を脱落させた(「PIV層の形態素は単独語の語釈がエスペラント文で
  測定不能=第17レンズと同じ理由で脱落」)。
  → **辞書の約35%を占める最下位層の割り当ては、内容の面で一度も検証されていなかった。**

  本レンズはその領域に別の真値を当てる: **エスペラント定義文そのもの**。
  PIVの定義は genus-differentia 形式なので、割り当てが既存資産から作られているなら
  **定義文に出てくる語根の漢字が、当の語根の漢字に現れる**はずである。
    flebit=脉炎 ← vejn=脉 + inflam=炎      aden=腺ᴬ ← gland=腺
  ※第6レンズも同じPIV定義文を使うが、用途は**トークン頻度のコーパス**であって真値ではない。
    定義文を割り当ての照合先に使うのは本レンズが初。

--------------------------------------------------------------------------------
■ ★先に3つの留保を書く(結論の読み方を誤らないために)
--------------------------------------------------------------------------------

  【留保1】これは第17レンズのような**独立**な外部真値ではない。
    PIV語根に字を当てた人間は当然この定義文を読んでいる。よって本指標が測るのは
    「割り当ての正しさ」ではなく **『既存の字から作られている』という関係が実際に成立しているか**
    という内部整合である。対照(無作為割り当て)との lift は意味を持つが、正しさの証明ではない。

  【留保2】**接地率の層差は品質の勾配ではない。** CSV2890 の 3.8% は欠陥ではなく、
    最優先層が**原子的な字(爱・水・手)を自前で持っている**ことの表れである。むしろ
    「上位層が新しい字を消費し、下位層が既存資産を再利用している」という**資源配分の指標**として読む。

  【留保3】**正しさの検出器としては再現率が低い。** 非接地の上位を目視すると
    petr=岩ᴾ(terkrusto の材料)・sapr=腐ˢᴿ(Neviva organika materio)・blink=闪ᴮ(Intermita lumo)・
    sukur=急救(unuan helpon al vunditoj)・anabol=合成(konstruo de protoplasmo)・erot=色ᴱᴿ(La seksa
    impulso)・stres=压力・toni=张 と、**いずれも割り当ては正しい**。定義文が別語彙で概念を
    説明しているだけである。よって非接地一覧は「是正候補」ではない。

■ ★接地の機構は2つあり、それぞれユーザーの原則の一方に対応する
--------------------------------------------------------------------------------

  (a) **同義語合流** — 定義文が指す語根が【同じ裸漢字群】に属する
      例 mikologi=菌学 ← 定義「Fungologio」=菌学ᶠ / nefr=肾ᴺ ← 「Reno」=肾 /
         aden=腺ᴬ ← 「Glando」=腺 / kole=胆ᴷ ← 「Galo」=胆 / blast=胚ᴮ ← 「embria」=胚
      = 「**割り当て漢字の種類を増やさないように努めてほしい**」の直接の実行
  (b) **合成** — 定義文の複数語根の【異なる字】が並んで描画を作る
      例 flebit=脉炎 ← vejn=脉+inflam=炎 / siliciat=硅盐 ← silik+sal=盐 /
         petr=岩ᴾ ← rok=岩,granit=花岗岩
      = 「**偽分解を超えて分解しての割り当てもして欲しい**」の直接の実行

    層         接地   (a)同義語合流   (b)合成   両方/不明
    CSV2890     14        13         1        0
    PEJVO       69        43        26        0
    PIV       1695       799       833       63

    字数別(機構の妥当性検査): 1字描画は定義上(b)が不可能なので全て(a)のはず →
      1字 910件 → (a)93% / 2字 629件 → (b)92% / 3字以上 239件 → (b)99%   … 予測どおり

  ★**PIV層の接地1,695件は、ほぼ半々で (a)799件 と (b)833件 に分かれる。**
    最下位層は「新しい字を作る」のではなく、**既存群への吸収**と**既存字の合成**の
    2つだけで賄われている。これがユーザーの2原則の、最下位層における実行量である。
