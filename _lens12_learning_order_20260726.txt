第12の検証レンズ: 学習順序シミュレーション —— 優先順位を【順序】として測る (2026-07-26 第27回続33)
========================================================================================

これまでの11レンズはすべて『いま誰がどの字を持っているか』(所有・被覆・一意性・1語根1字)の
静的検査だった。本レンズはユーザーの優先順位を宣言どおりの【学習順序】と読み、
  CSV2890(Unified_Level昇順) → PEJVO本体(〜44104) → PEJVO追補(〜44440) → PIV(44441〜)
の順に語根を1つずつ習得する学習者を模擬して、
  (1) 何語根を覚えた時点で各層の語の何%が【全分節既習】で読めるようになるか(累積可読曲線)
  (2) ★前方参照: 高優先層の語が低優先層の語根の字を要求する箇所の悉皆列挙
を測った。(2)は「優先順位が守れていない」ことの最も直接的な証拠になりうる。

※測定上の要点: 分節の描画は語根自身の disp とは限らない(homonym台帳/インライン規則で別の字になる。
  例 au^t/o/mobil/o は mobil=挂饰[モビール]でなく 动ᴹᴮ)。そこで【実際に描画されたトークン】から
  §9の復号どおりに所有語根を引き当ててから層を判定した(v1の素朴実装は挂饰と誤報していた)。

[12-2] ★前方参照は 0.9% しかなく、しかも全件が構造的に良性
----------------------------------------------------------------------------------------

  CSV2890層の語 2,984件のうち、下位層の語根の字を要求するもの = **27件(0.9%)**
  PEJVO層の語 43,216件のうち PIV層の語根を要求するもの = 367件(0.8%)

  27件はすべて『CSV2890が【複合語】を見出しに持ち、その成分を単独見出しに持たない』型:
    biologio はあるが bio は無い / kilometro はあるが kilo は無い / feminismo はあるが femin は無い …
  つまり優先順位の違反ではなく、CSV2890語を形態素に分解した結果として
  『CSV自身が列挙していない成分』が露出する、分解の構造的帰結である。

  ★負担の内訳(学習者が余分に覚えるものは何か):
    ・21件 = 字はCSV2890層の他の語にも出る既習字で、**余分なのは識別子だけ**
        生ᴮᴼ(bio) 学ᴸᴳ(logi) 心ᴾˢ(psik) 境ᴱ(eko) 记ᴳ(graf) 志ᴳ(grafi) 千ᴷᴵ(kilo) 直ᴼ(orto)
        械ᴹᴷ(mekan) 械ᴹᴺ(meh^an) 民ᴰᴱ(demokrat) 通ᴰ(dia) 新ᴺᴱ(neo) 女ᶠᴱ(femin) 胃ᴳ(gastr)
        镜ˢᴷ(skop) 动ᴹᴮ(mobil) 操ᴳᴵ(gimnast) 学ᴵ(ik) 分ᴰᶜ(deci) 吾(ego)…
    ・6件 = 字そのものがCSV2890層でその語にしか出ない専用字
        厘(centi/metr/o) 毫(mili/metr/o) 哲(filozof/i/o) 吾(ego/ist/o) 乙(et-=etil) 傲(arog/ant/a)
      → いずれも **その語のためだけに存在する字** で、より高優先の語根が何かを失ってはいない。
        (専用字なので、CSV2890語根が識別子付きに落ちる逆転は起きていない=[I] CSV2890_LOSES_BASE=0 と整合)

  ⇒ **前方参照27件はいずれも是正すべき優先順位違反ではない**。

[12-3] ★実際に見つかった不整合: SI接頭辞ファミリで 厘 と 毫 の割当が逆だった
----------------------------------------------------------------------------------------

  前方参照を1件ずつ潰す過程で、まったく平行な2つの群が逆向きになっているのを発見した。

    群 厘 : centi = 厘(無印)   / centimetr = 厘ᶜᴹ    ← 接頭辞側が無印
    群 毫 : milimetr = 毫(無印) / mili = 毫ᴹᴵ         ← ★逆

  実描画数(両版の見出し分節を実測。F列は出現回数ではないので使わない):
    mili 8回(mili/metr・mili/gram・mili/bar・mili/amper・mili/sivert) vs milimetr 1回(学術版の未分解形のみ)
    centi 6回 vs centimetr 1回

  CSV2890語 milimetro は学習者版では mili/metr/o と分解されるので、接頭辞側を無印にすると
  **最優先層の語がそのまま 毫/米/o と読める**。判定基準は第27回続27でユーザーが示した
  『語根分解に忠実な方を無印にする』(dermapter=皮翅・kilopod=千足 と同じ論理)。
  → `_base_override.tsv` に 毫→mili を追加(厘→centi の1行と対にした)。
     改善7行(学習者5+学術2) / 後退1行(学術 milimetr/o=毫ᴹᴹ)。字種・分解・被覆は不変。

[12-4] ★正本ドリフト2回への対応 —— 前日新設した[K]監査が初日で3件検出

  [K]監査(第11レンズで新設)が『漢字描画のある新規見出し』として正確に検出:

   ① metakarp/o → meta/karp/o   … ★偽の友。karp が【魚】コイ=鲤 を拾い
        `meta/karp/o⟦超ᴹ/鲤/o⟧`(超えた鯉)になった。分割前は metakarp=掌骨 の1語根。
        → 台帳に sep 追加: karp(解剖 karpo=手根)→腕ᴷ。`超ᴹ/腕ᴷ/o`(手根を超えた部位=中手/掌骨)。

        (見出しがコイ義と同綴2行のため word-scoped では弁別できず、語釈scopedのインライン規則で対応。

[12-5] SI接頭辞の悉皆点検で露出した偽の友(mili/o)
----------------------------------------------------------------------------------------

  [12-3]の実測中に `mili/o⟦毫ᴹᴵ/o⟧:【植】雑穀（アワ，キビ，ヒエ，モロコシなど）` を発見。
  mili/o は SI接頭辞 milli- ではなく【植】Milium(キビ属)で、語釈自身が
  >>setario >>panico >>ekinoklo >>sorgo と同じイネ科雑穀を相互参照している。
  その一族は既に 粟 群(panic=粟・setari=粟ˢ・ekinokl=粟ᴱ)で揃っていた。
  → 台帳に sep 追加: mili(【植】Milium)→粟ᴹ。新字ゼロ・既存群への合流(生物名割当5基準の①)。
     SI義 mili/metr・mili/gram・mili/bar・mili/amper・mili/sivert は disc外で 毫 を維持。
  他のSI接頭辞(deka/hekto/kilo/mega/deci/mikro)には同種の同綴別語見出しが無いことも確認済み。

結論
----------------------------------------------------------------------------------------

  優先順位は【順序】として測っても守れている:
    ・CSV2890層の語根だけで CSV2890語の99.1%が完全に読める。全チェックポイントで層順は単調。
    ・前方参照は0.9%しかなく、27件すべてが『CSVが複合語だけを列挙している』ことの構造的帰結で、
      21件は識別子だけの負担・6件は当該語専用字。高優先の語根が何かを奪われた事例は0件。
  是正したのは、この測定の過程で露出した4点だけ:
    ① meta/karp の偽の友(鲤→腕ᴷ) + 分割前から存在した karp/o【解】の同型誤読
    ② karbaz/on の分数接尾誤適用(ケトン-one→ラテン)
    ③ SI接頭辞 厘/毫 の無印割当の非対称(毫→mili で厘と揃えた)
    ④ mili/o【植】Milium の偽の友(毫ᴹᴵ→粟ᴹ)
  漢字の種類は1字も増やしていない(全て既存字・既存群への合流)。分解(スラッシュ)は一切触っていない。
