■ 空白の所在 — 第1〜30が漢字の「中身」を一度も見ていない

  第1〜30レンズは、割り当てた漢字を **内部構造ゼロの原子記号** として扱ってきた。
  意味・頻度・層・履歴・分節・外部語彙まで測ったが、**字の形そのもの**は一度も測っていない。

  ★これは偶然の抜けではなく、第23レンズが【定義によって】閉じた空間である:
    ・`_lens23_near_collision_20260728.txt:86`
        「そして1字面は **転置衝突も高重複近傍も構造的に起こり得ない**。
          最優先層の保護は…**そもそも短い面をもらえたこと自体** から来ている。」
    ・記録済みの落とし穴「**1字面どうしの距離1は『全く別の字』であって近傍ではない**」
  つまり第23は「最優先層は91.0%が1字面だから安全」と結論したが、その安全は
  **『その1字が他の字と見間違えられない』という、一度も検定されていない仮定**の上に乗る。
  己/已・未/末・土/士 は文字列距離では「全く別の字」だが、読者は現に取り違える。

  ★先行の悉皆確認(第27・第28で犯した「既出を新発見と称する」失敗の再発防止):
    ・`漢字化方針_v2_作業ログ§14_*.md` / `_メモリ層アーカイブ_圧縮前_20260728.md` の
      「画数」は**全て P値の式(E=lat/st, D=総画数)の文脈**で、字形の話は一件もない。
    ・両文書の「弁別」は**全て意味の弁別**(同綴弁別・語釈弁別・識別子弁別)であり、
      視覚的弁別ではない。
    ・字の形に触れた記述は全プロジェクトで**ただ1箇所**:
      `エスペラント語根_識別子付与アルゴリズム_仕様書.md:54`
      「anĉov=鱼ᴬᶜ̂ と anchov=鱼ᴬᶜ … `ᶜ̂` vs `ᶜ` の差で区別=視覚的に紛らわしいが現状許容」
      → **1件を既知として許容した記述はあるが、悉皆調査は無い**(本レンズ[E]で36件と判明)。

  ★第30の裁定(続69)を通過するか: 通過する。第30は「中国語として読むと別語」という
    **体系外の読者モデル**に依存していたため裁定で退けられた。本レンズは
    「己 と 已 を見分けられなければ **si か jam か**が決まらない」という
    **体系内部の読字失敗**であり、外部言語の知識を一切前提としない。

■ 測り方 — 閾値は恣意でなく「再現率と偽陽性率の組」で示す
--------------------------------------------------------------------------------

  一级3500 の全字を宋体 64px で描画し、(a)2値ビットマップの IoU と
  (b)ガウスぼかし後の余弦類似(=速読・低視力での見えを模す)の**両方**で測る。
  閾値は教科書的な形近字35対を種集合として較正した:

    厳(IoU≥0.45 かつ blur≥0.94): 種集合の再現率 16/35 = 46%
                                  無作為 612万対中 784対 = **偽陽性率 0.013%**
  ★書体依存を潰す: 黑体系は線が太く同じ絶対閾値では 7,153 対に膨れる。
    そこで第2書体の閾値は**同じ分位点**に取り(IoU≥0.57/blur≥0.96)、
    **両書体で成立した 278 対だけを採用**した(採用集合での種集合再現率 40%)。

  ★再現率が4割なので、以下の件数は全て【下限】である。
  ★既知の限界: 曰/日 は IoU=0.092 で拾えない。画素重なりは「同じ部品を同じ位置に持つ」型を
    拾い、「縦横比だけ違う」型は拾えない。

■ [A] 書字負荷 — R3「少画数優先」は層間の梃子ではない
--------------------------------------------------------------------------------

  基準: 一级3500 の平均画数 = 9.70 画

  型レベル(語根1件=1票)         面の総画数   面の字数   1字あたり画数

  延べ出現(注入出力・学習者版)    面の総画数   面の字数   1字あたり画数

    PEJVO    15,485                11.47      1.29        8.87
    PIV       3,620                11.03      1.29        8.57

  ★総画数は層順に単調(9.49<12.12<14.07)だが、**その差を作っているのは字数**であり、
    **1字あたり画数は層間でほぼ平坦**(むしろ CSV2890 8.85 > PIV 8.22 と僅かに逆)。
    = R3 は全層で効いている(全層が基準9.70を下回る)が、**層を分ける梃子は §4.3③「文字数」**。
    これは方針が定めた採否比較順(①意味透明性→②基礎漢字→③文字数→④画数)そのままの
    結果であり、違反ではない。第23の「短い面をもらえたこと自体が保護」を画数の側から裏付ける。

■ [C] 語根の面の形近衝突 — ★ここで最優先層が逆転する
--------------------------------------------------------------------------------

  「ある面の1字を形の双子に読み違えると、別語根の面になる」対 = **873 組**
    うち **識別子マークの差で救済 763 組(87.4%)** / マークまで同じ = **110 組**

  層別(マークでも救済されない面を持つ語根の割合)
    文法層     9/224   4.02%
    CSV2890  118/2464  **4.79%**   ← 最も高い
    PEJVO     55/3847  1.43%
    PIV       10/3878  0.26%
  延べ出現で重み付けても 文法1.57% / **CSV2890 5.57%** / PEJVO 2.44% / PIV 0.30%

  ★**優先順位に対して逆転している**。しかもこれは欠陥ではなく**構造的な帰結**である:
    最優先層は「無印(マーク無し)の裸形」を与えられる層である(第8・第25・第27が測った特権)。
    マークが無いということは、**形を見誤ったときに引き止めるものが何も無い**ということでもある。
    下位層は必ずマークを背負うので、形が似ていてもマークが違えば面は区別される。
    = **識別子機構は下位層だけを形の誤読から守っており、最優先層は素手である。**
    第23が「1字面だから安全」と読んだものは、形空間では「1字面だから無防備」でもあった。

  ★対照(面の長さ構造を保ったまま、字を1字ずつ同じ画数の別字へ無作為に写す・10回)
    全体 747.5 組 → 実際 873 組 = **偶然の 1.17 倍**
    マーク未救済 106.1 組 → 実際 110 組 = **偶然の 1.04 倍**
    → **意味で選んだ結果は、形の分離という点では偶然と同じ**。良くも悪くもない。
      これは当然で、§4.3 の採否比較順に**形の弁別性という項目が存在しない**からである。

  ★★したがって逆転は「最優先層の字選びが下手」を意味しない。対照が構造(面の長さ分布)を
    保っている以上、実際≒偶然(1.04倍)は **逆転が構造だけで説明しきれる** ことを示す。
    構造の中身は2つとも最優先層であることの帰結である:
      ①マークが無い(下位層は必ずマークを負うので形が似ても面が分かれる)
      ②面が1字である(1字面の形の双子は、2,261字の中で高確率で別の実在面になる。
        2字以上の面はその双子も実在せねばならず、空間がはるかに疎)
    第23が「1字面だから安全」と読んだ同じ構造が、形空間では「1字面だから無防備」になる。

  マークでも救済されない対の危険度上位(min F = 両方とも実際によく出る)

■ [D] ユーザー自身の配信テキストでの実害 — 最終的に 1 対
--------------------------------------------------------------------------------

  本文の漢字連続 896種。形近衝突対のうち **両方の面が本文に現れる = 12 対**、
  そのうちマークでも区別されない = **4 対**。
  さらに**語形(ラテン語尾込み)まで一致するか**を実測すると:

    jam(已) ⇔ si(己)      → **一致しない**。已=[已] / 己=[己a 己aj 己an 己n]
      ★si は再帰代名詞ゆえ**主格になれない**(主語になれない)。常に -a/-n/-aj を伴う。
        jam は副詞で語尾を取らない。**エスペラント文法が構造的に衝突を防いでいる。**
    ten(持) ⇔ ot(待)      → 一致しない。本文の 待 は全て 待ᴬ(atend)でマーク救済。
    last(末) ⇔ futur(未)  → 一致しない。末=[末a 末aj 末an…] / 未=[未o] で語尾が違った。
    **korp(体) ⇔ ripoz(休) → ★一致する。体o(10回) ⇔ 休o(2回)**

  ★★実配信テキストで本当に取り違えうるのは **1 対(体o=korpo / 休o=ripozo)** だけである。

■ [F] 形の弁別性を割り当て基準に後付けできるか — 供給ではなく R4 が制約
--------------------------------------------------------------------------------

  一级3500 の在庫: 使用済 2,261 / 未使用 1,239。
  未使用のうち**使用済のどの字とも形が近くない = 1,124 字(90.7%)**。
  → **字の供給は潤沢**。だから残っている衝突は「安全な字が無かった」からではない。

  制約は R4(意味の透明性=最重要)の側にある。実例 ripoz=休 の代替を探すと:
    歇 = paŭz が使用済 / 息 = spir が使用済 / 闲 = sinekur が使用済 /
    憩 = **一级外**(R2違反) / 卧・逸 は空きだが「休息」ほど透明でない。
  → **残る衝突は、透明性を形より優先した結果**であり、§4.3 の採否比較順そのままである。

■ 結論 / この報告の弱さ
--------------------------------------------------------------------------------

  ・**新しい失敗様式を1つ同定した**: 字を原子記号でなく形として見たときの取り違え。
    第23が「1字面だから構造的に安全」と閉じた空間に、実際には危険が残っていた。
  ・★**最も価値のある発見は逆転の構造的理由**: 識別子マークは形の誤読に対しても
    防護として働くが(87.4%を救済)、**マークを持たない最優先層だけがその防護の外にある**。
    第25・第27が「無印は最優先層の特権」と測ったものは、形空間では負債でもあった。
  ・ただし**語形レベルで測り直すと 0.40%・層間平坦**で、実配信テキストでの実害は
    **1対(体o/休o)**。逆転は語根の面という測定単位が作っていた面が大きい。
  ・**本レンズ由来の是正0件**。字の供給は潤沢(90.7%)なので、残る衝突は R4 優先の意図的な帰結。
    (別件で DICT同期protocolが露出させた誤友2件=glos舌ᴳ/rotaラテン は是正した)
  ・★**弱さ**: (1)独立検証を行っていない(自己検証のみ)。(2)類似度は宋体・黑体系の
    2書体・64px の画素重なりで、実際の読字サイズ・字間・周辺視は模していない。
    種集合の再現率40%＝**件数は全て下限**で、曰/日 型(縦横比違い)は原理的に取りこぼす。
