4-1. 에스페란토 어근 한자 할당표kanji_assign / kanji.html

사전·기반 데이터

어근에 어떤 한자가 할당되어 있는지 확인하는 뷰로, 프로젝트 전체의 대응표입니다.

입력검색어(어근·한자·식별자·의미)
출력해당하는 어근, 한자, 식별자, 분류, 빈도, 획수, 의미

적합한 용도: 한자화 문장을 쓰기 전의 확인, 식별자 확인, 사전 유지 관리.

구체적으로 할 수 있는 것

  • 어근, 한자, 식별자, 의미로 검색할 수 있다.
  • basic / pejvo / piv / prep / suf / pref / correl 등의 분류로 좁혀서 볼 수 있다.
  • 같은 한자를 공유하는 어근 그룹을 확인할 수 있다.
  • 식별자가 붙은 항목만 표시할 수 있다. 예: 出ᴱᴷ, 穿ᴾ, 在ᶜ̂.
할당표 열기(kanji.html) 복합어 뷰(words.html) GitHub

4-2. 한자화 에스페란토 입력 에디터kanji-esperanto-monaco

입력·글쓰기

Monaco Editor에서 에스페란토 어근을 입력하면 한자 후보를 제시해 주는 웹 에디터입니다.

입력에스페란토 어근·문장
출력한자화 에스페란토 문장

적합한 용도: 일기·게시글·예문 등을 직접 입력하면서 정성껏 한자화하고 싶을 때.

구체적으로 할 수 있는 것

  • bon이라고 입력하면 良 같은 한자 후보가 나타나, 골라 넣을 수 있다.
  • 후보에는 식별자가 붙은 한자도 포함된다.
  • 할당 검색 패널에서 특정 한자에 대응하는 어근을 역으로 찾을 수 있다.
  • 복사, 붙여넣기, 전체 선택, 공유, 로컬 저장, 기록 복원을 지원한다.
  • 온라인에서 한 번 열어 두면 오프라인에서도 쓸 수 있도록 고려되어 있다.

4-3. 한·중·일 주석 루비·한자화 도구esperanto-radiko-cjk-annotator

자동 변환·독해 보조

일반 에스페란토 문장을 어근으로 분해하여, 한국어·중국어·일본어 주석 루비, 한자 루비, 태그 없는 한자화 문장으로 변환합니다.

입력일반 에스페란토 문장, 또는 텍스트 파일
출력루비 HTML, 편집 가능한 HTML, 태그 없는 한자화 문장, 다운로드 파일

적합한 용도: 긴 문장을 일괄로 루비화·한자화하고 싶을 때. 독해 지원이나 게시용 변환에 적합합니다.

구체적으로 할 수 있는 것

  • 주석 루비: 어근 위에 한·중·일 번역어를 표시한다.
  • 한자 루비: 한자를 본문으로 하고, 에스페란토 어근을 루비로 표시한다.
  • 순수 치환: HTML 태그가 없는 한자화 텍스트를 출력한다.
  • 직접 입력·텍스트 파일 업로드를 지원한다.
  • %...%는 변환하지 않기, @...@만 변환하기 같은 부분 지정이 가능하다.
  • 잘못된 어근 분해를 GUI에서 보정하고, user_corrections.json으로 저장·복원할 수 있다.
한국어판 열기 일본어판 중국어판 GitHub

4-4. 한자화 에스페란토 역변환기kanjized-esperanto-reverter

검증·복원

한자화 에스페란토 문장을 소문자 알파벳 표기로 되돌리는 도구입니다.

입력한자화 에스페란토 문장
출력소문자 알파벳 표기의 에스페란토 문장(어근·어미·기호 포함)

적합한 용도: 한자화 문장의 검증, 원문 복원, 변환 규칙 테스트. 어근 구분 표시가 없기 때문에 복합어에서는 모호성이 남을 수 있습니다.

구체적으로 할 수 있는 것

  • PEJVO/PIV 2026-06-20판, 스니펫용 2열 CSV, 사용자 지정 CSV를 전환하며 쓸 수 있다.
  • 위 첨자 식별자를 포함한 한자 표기를 인식할 수 있다.
  • 한자와 알파벳이 섞인 문장도 처리할 수 있다.
  • 변환 결과를 텍스트로 다운로드할 수 있다.
역변환기 열기 GitHub

4-5. 에스페란토 4지선다 학습 앱esperanto_quiz

학습·연습

한·중·일 대응 단어·예문 4지선다 퀴즈입니다. PC판과 모바일판이 있으며, 음성·점수·랭킹도 지원합니다.

입력퀴즈 설정, 답 선택
출력정답·오답, 점수, 복습, 랭킹

적합한 용도: 어휘·예문을 반복 학습하고 싶을 때. 스마트폰으로 매일 연습하는 용도에 특히 좋습니다.

구체적으로 할 수 있는 것

  • 단어 퀴즈: 2890개의 중요 어휘를 품사·레벨·그룹별로 출제한다.
  • 예문 퀴즈: Topic / Subtopic / Level을 골라 출제한다.
  • 출제 방향은 '에스페란토→번역어', '번역어→에스페란토'의 두 가지다.
  • 틀린 문제만 정답을 맞힐 때까지 다시 내는 스파르타 모드가 있다.
  • 음성 재생, Google Sheets 랭킹, 모바일용 localStorage 저장형 UI를 지원한다.
  • 일본어판·중국어판·한국어판은 각각 해당 언어의 번역어 열을 사용한다.

4-6. 에스페란토 음성 합성paroligu

음성 교재 제작

에스페란토 문장을 RHVoice의 Spomenka 음성으로 읽어 주고, WAV 또는 MP3로 저장할 수 있습니다.

입력에스페란토 문장, 음성 설정, 저장 파일명
출력브라우저 재생 음성, WAV, MP3

적합한 용도: 예문 낭독, 발음 확인, 학습용 음성 파일 제작.

구체적으로 할 수 있는 것

  • Unicode 표기와 x 표기법 모두 지원한다.
  • 속도·높낮이·음량을 조절할 수 있다.
  • MP3 비트레이트를 선택할 수 있다.
  • 브라우저에서 재생하고, WAV/MP3로 저장할 수 있다.
  • Streamlit Cloud에서도 RHVoice를 쓸 수 있도록, 시작할 때 필요한 패키지의 압축을 풀어 설치하는 구조다.

4-7. 에스페란토 음성 실시간 전사Ubuntu판 / Windows판

대화·회의 자막

Zoom이나 Google Meet의 에스페란토 대화를 실시간으로 전사하고, 일본어·한국어 번역, Zoom 자막, 웹 자막 보드, Discord 게시로 내보낼 수 있는 로컬 도구입니다.

입력마이크 또는 PC 오디오 루프백, API 키, Zoom CC URL, 번역 설정
출력전사, 번역, Zoom 자막, 웹 자막 보드, 로그, Discord 게시

적합한 용도: 온라인 수업, 회의, 발표, 에스페란토 대화의 기록. Streamlit Cloud가 아니라 로컬 PC에서 실행하는 도구입니다.

구체적으로 할 수 있는 것

  • Speechmatics Realtime STT를 중심으로, Vosk나 Whisper를 예비로 사용할 수 있다.
  • Zoom Closed Caption API로 자막을 보낼 수 있다.
  • 웹 UI에서 최신 자막과 기록을 표시할 수 있다.
  • 일본어·한국어 등으로 번역해 표시하는 기능을 지원한다.
  • Discord Webhook으로 확정된 문장과 번역을 한꺼번에 게시할 수 있다.
  • Ubuntu판은 PipeWire/PulseAudio 루프백 설정을 도와주고, Windows판은 VB-Audio/VoiceMeeter 등을 전제로 진단·설정을 지원한다.

5추천 활용법

목적추천하는 흐름
한자화 문장을 일괄로 만들기일반 에스페란토 문장을 준비 → CJK Annotator에서 '순수 치환' 또는 '한자 루비'를 선택.
세부까지 직접 다듬기kanji_assign에서 할당을 확인하면서, Monaco 입력 에디터에서 어근마다 후보를 고른다.
식별자가 올바른지 확인하기kanji_assign에서 같은 글자 그룹과 식별자를 확인하고, 필요하면 Monaco나 Annotator의 결과를 수정한다.
한자화 문장을 검증하기Reverter로 소문자 에스페란토로 되돌려, 의도하지 않은 어근으로 되돌아가지 않았는지 확인한다.
학습 교재 만들기Quiz로 어휘·예문을 연습하고, paroligu로 예문 음성을 만든다.
회의·수업에서 사용하기Ubuntu/Windows 전사 도구를 로컬에서 실행하여, 웹 자막·번역·Zoom 자막으로 내보낸다.
