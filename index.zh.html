1整体概览：这套工具是做什么的

位于核心的是一部「为世界语词根分配汉字的词典」。以这部词典为基础，就能撰写汉字化文本、批量转换普通世界语文本、还原汉字化文本，并进一步扩展到学习、语音、会话字幕等一系列流程。

4各工具说明

查

4-1. 世界语词根汉字分配表kanji_assign / kanji.html

词典·基础数据

用于查看某个词根被分配了哪个汉字的界面。它是整个项目的核心对照表。

输入检索词（词根·汉字·标识符·词义）
输出对应的词根、汉字、标识符、分类、频率、笔画数、词义

适合的用途：撰写汉字化文本前的确认、标识符的确认、词典维护。

具体能做什么

  • 可按词根、汉字、标识符、词义检索。
  • 可按 basic / pejvo / piv / prep / suf / pref / correl 等分类进行筛选。
  • 可确认共享同一汉字的词根组。
  • 可只显示带标识符的条目。例：出ᴱᴷ、穿ᴾ、在ᶜ̂。
打开分配表（kanji.html） 复合词视图（words.html） GitHub
写

4-2. 汉字化世界语输入编辑器kanji-esperanto-monaco

输入·撰写

在 Monaco Editor 上，输入世界语词根即可提示汉字化候选的 Web 编辑器。

输入世界语词根·文本
输出汉字化世界语文本

适合的用途：想通过手动输入细致地把日记、投稿文、例句等汉字化时。

具体能做什么

  • 例如输入 bon 得到 良，可从词根中选择汉字候选。
  • 候选中也可包含带标识符的汉字。
  • 在分配检索面板中，可对某个汉字反查其对应的词根。
  • 支持复制、粘贴、全选、共享、本地保存、历史恢复。
  • 在线打开过一次后，也可离线使用。
打开编辑器 GitHub
转

4-3. 日中韩释义旁注·汉字化工具esperanto-radiko-cjk-annotator

自动转换·阅读辅助

对普通世界语文本进行词根分解，转换为日语·中文·韩语的释义旁注、汉字旁注，以及无标签的汉字化文本。

输入普通世界语文本，或文本文件
输出旁注 HTML、可编辑 HTML、无标签汉字化文本、可下载文件

适合的用途：想把较长的文本批量加旁注·汉字化时。适合阅读辅助或投稿用转换。

具体能做什么

  • 释义旁注：在词根上方显示日中韩译词。
  • 汉字旁注：以汉字为正文，将世界语词根作为旁注。
  • 纯文本替换：输出不含 HTML 标签的汉字化文本。
  • 支持手动输入·文本文件上传。
  • 可进行部分指定，例如不转换 %...%、只转换 @...@。
  • 可在 GUI 中修正错误的词根分解，并保存为 user_corrections.json 以供恢复。
打开中文版 日语版 한국어판 GitHub

用这个工具做成的现成读物：Claude Piron《Vere aŭ Fantazie》全 46 章 — 中文注释版 / 日语旁注版

还

4-4. 汉字化世界语逆向转换器kanjized-esperanto-reverter

验证·还原

将汉字化世界语文本还原为小写字母写法的工具。

输入汉字化世界语文本
输出小写字母写法的世界语文本（包含词根·词尾·符号）

适合的用途：汉字化文本的验证、原文还原、转换规则的测试。由于不带词根分隔，复合词可能存在歧义。

具体能做什么

  • 可在 PEJVO/PIV 2026-06-20版、片段专用的两列 CSV、自定义 CSV 之间切换。
  • 可识别包含上标标识符的汉字写法。
  • 也支持汉字与字母混排的文本。
  • 可将转换结果作为文本下载。
打开逆向转换器 GitHub
学

4-5. 世界语四选一学习应用esperanto_quiz

学习·练习

日中韩对应的单词·例句四选一测验。有 PC 版和手机版，并支持语音·得分·排行榜。

输入测验设置、答案选择
输出正误、得分、复习、排行榜

适合的用途：想反复学习词汇·例句时。尤其适合用手机每天练习。

具体能做什么

  • 单词测验：将 2890 个重要词汇按词性·级别·组别出题。
  • 例句测验：选择 Topic / Subtopic / Level 出题。
  • 出题方向为「世界语→译词」「译词→世界语」。
  • 设有「斯巴达模式」：将答错的题反复出题，直到答对为止。
  • 支持语音播放、Google Sheets 排行榜、面向手机的 localStorage 保存型 UI。
  • 在日语版·中文版·韩语版之间切换译词列。
打开中文版 日语版 한국어판 GitHub
声

4-6. 世界语语音合成paroligu

语音教材制作

用 RHVoice 的 Spomenka 语音朗读世界语文本，并可保存为 WAV 或 MP3。

输入世界语文本、语音设置、保存文件名
输出浏览器播放音频、WAV、MP3

适合的用途：例句朗读、发音确认、学习用语音文件制作。

具体能做什么

  • 同时支持 Unicode 写法与 x记法。
  • 可调整语速·音高·音量。
  • 可选择 MP3 比特率。
  • 可在浏览器播放，并保存为 WAV/MP3。
  • 采用在启动时展开所需软件包的设计，使得在 Streamlit Cloud 上也能使用 RHVoice。

幕

4-7. 世界语语音实时转写Ubuntu 版 / Windows 版

会话·会议字幕

将 Zoom 或 Google Meet 的世界语会话实时转写，并可接入日语·韩语翻译、Zoom 字幕、Web 字幕页、推送到 Discord。这是一款在本地运行的工具。

输入麦克风或 PC 音频回环、API 密钥、Zoom CC URL、翻译设置
输出转写、翻译、Zoom 字幕、Web 字幕页、日志、推送到 Discord

适合的用途：在线课堂、会议、演讲、世界语会话的记录。这是在本地 PC 上运行、而非在 Streamlit Cloud 上运行的工具。

具体能做什么

  • 以 Speechmatics Realtime STT 为主，可将 Vosk 或 Whisper 作为备用。
  • 可向 Zoom Closed Caption API 发送字幕。
  • 可在 Web UI 中显示最新字幕与历史记录。
  • 支持向日语·韩语等的翻译显示。
  • 可通过 Discord Webhook 将确定文本与翻译一并推送。
  • Ubuntu 版为 PipeWire/PulseAudio 的回环提供辅助支持，Windows 版则以 VB-Audio/VoiceMeeter 等为前提提供诊断与设置支持。

5如何选用

目的推荐的流程
批量制作汉字化文本准备好普通世界语文本 → 在 CJK Annotator 中选择「纯文本替换」或「汉字旁注」。
想精细调整每个细节在 kanji_assign 中确认分配的同时，在 Monaco 输入编辑器中逐个词根选择候选。
确认标识符是否正确在 kanji_assign 中确认同字组与标识符，必要时修正 Monaco 或 Annotator 的结果。
验证汉字化文本用 Reverter 还原为小写世界语，检查有没有还原出意料之外的词根。
制作学习教材用 Quiz 练习词汇·例句，用 paroligu 制作例句语音。
用于会议·课堂在本地启动 Ubuntu/Windows 转写工具，接入 Web 字幕·翻译·Zoom 字幕。
