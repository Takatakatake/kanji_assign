第18レンズ「語義単位の被覆（多義の取りこぼし）」 2026-07-27 (第27回続42)
  — ユーザー原則の【後半】を初めて測る —

■ なぜこのレンズが新しいか

ユーザーは毎回この原則を添える:

  「一つの語根に複数の全く異なる意味が存在する場合は、基本的には、可能な限り解釈を
    頑張って、割り当て漢字の種類を増やさないように努めてほしいが、
    全く意味が異なる場合は、新たな割り当ての検討も致し方ないと考えている。」

第15レンズはこの【前半】を測った = 「字種を増やした語根 = 138/10,643 = 1.30%」。
つまり「増やしすぎていないか」は測ってあった。

しかし【後半】は一度も測っていない。すなわち
  **増やすべきなのに増やしていない取りこぼし（false negative）はどれだけあるか。**
語根単位の集計ではこれは絶対に見えない。1字が割り当たっていれば「割当済み」に数えられ、
その字がその語根の第2義・第3義を全く表していなくても指標は満点だからである。

そこで測る単位を【語義】に落とした。辞書の語釈を語義単位に割り(この辞書は ; が
語義境界、, が同義語列挙)、各語義に対して割り当て字が接地するかを個別に判定する。

--------------------------------------------------------------------------------
■ 主要結果 ①: 最優先層を中国語訳(字種一致=真値)で測る
--------------------------------------------------------------------------------

  多義語根 = 1,554 / 総語義 = 4,020
  ★ 1字が背負う語義 = 2.59

  全語義に接地       =   415 (26.7%)
  一部の語義のみ接地 = 1,042 (67.1%)
  どの語義にも非接地 =    97 ( 6.2%)
  語義接地率         = 56.9%

  ★ 第15レンズの数字と並べると、この方針の実行度が一意に決まる:
       1字あたり 2.59 語義を背負わせて、字を分割したのは 1.30% だけ。
     「可能な限り解釈を頑張って字種を増やさない」は、努力目標ではなく
     実際に大規模に実行されている。

  1字が最も多くの語義を背負っている例:
    ĉel  = 胞   小室，囚室；细胞，蜂房；（政）基层组织；（理）电子管，电池单元；
                （棋）格；（计算机）存储单元                          ← 8語義
    radi = 射ᴿ  光线，射线，放射线；放射状物；（数）半径；（机）辐条；
                （转）光明，光辉；（通）无线电广播，广播电台；收音机   ← 7語義
    nod  = 结ᴺ  结，结点，交点；要点；（动植物）节、瘤；（解）结节；
                （物理/光学）波节、节点；（航海）节；（计）节点
    pren = 拿   拿；取；接受；选择；采用；把…当作
    ŝveb = 翔   悬浮，漂浮，滑翔；轻轻掠过；（在水中）悬浮；
                《转》（心中）浮现；悬而未决

  これらは全て【同一語の意味拡張】であり、1字でまとめるのが方針どおり。
  ラテン語 cella / radius / nodus が持つ意味の広がりを、漢字1字が同じ広がりで
  受けている。方針の「解釈を頑張って」が具体的に何を指すかがこの表である。

■ 候補218件を全件目視 → 是正0件
--------------------------------------------------------------------------------

「分野タグが異なる語義に接地していない」= 学習者が体系的に読み違える恐れがある、
という条件で 218件(既裁定/台帳7 + 新規211)を抽出し、全件目視した。

(1) 高頻度側（重み=影響見出し数の大きい順）
      ŝarg = 装   装填する / ロードする(情) / 充電する(電)   … 全て「載せる」
      aparat=器ᴬ  器官 / 装置(情)                             … 同一語
      dens = 密   濃い / (ネガが)濃い(写)                     … 同一語
      divid= 分ᴰ  分ける / 割る(数)                           … 同一語
      operaci=操  操作する / 手術する(医) / 演算する(数)      … ラテン operatio
      ĉel  = 胞   細胞 / 電池セル(理) / ハチの巣穴(虫)        … ラテン cella
      tur  = 塔   塔 / チェスのルーク(遊)                     … ルークは塔
    → 全て**同一語の意味拡張**。方針は「統合すべき」と明言しており、現状が正しい。

(2) 生物分野と抽象分野が同居する型（ribosom/rib 事件と同型なので特に警戒して精査）
      kancer = 癌    がん / イチョウガニ属(Cancer)   … ラテン cancer=カニ。同一語
      nimf   = 精ᴺ   ニンフ(神話) / 若虫(虫) / 小陰唇(解) … ラテン nympha。同一語
      radius = 半径  半径 / 橈骨(解)                  … ラテン radius。同一語
      romb   = 菱    菱形 / ヒラメの一種(魚)          … 形から命名された属名
      poligon= 多角  多角形 / タデ属(Polygonum)       … 同一ギリシャ語源
      lent   = 豆ᴸᴺ  レンズ豆 / レンズマメ属          … 同一
      ambos  = 铁床  鉄床(かなとこ) / きぬた骨(解)    … 同一比喩
      skarab = 甲ˢ   甲虫 / タマオシコガネ属          … 同一
    → **学名が日常語から命名された型**ばかりで、統合が正しい。
      「別語源の同綴異義 → 分割可 / 同一語の意味拡張 → 統合」の判定基準に照らし、
      分割すべきものは**新規ゼロ**。

(3) 既裁定の再確認
    方針書§14.2.1 の確定裁定(plum羽統一・sinus洞ˢ統一・mat/kanon分割維持・sol胶ˢ・
    kuriラテン・orkid/panikl/arke・文字名6行・klement)と台帳(_homonym.tsv)の
    sep145行/amb42行は、スクリプト側で「既検討」として自動的に別掲した。
    続39の事故（据置記録を見落として7件覆した）の再発防止を機構に埋め込んである。

■ 結論
--------------------------------------------------------------------------------

  ・最優先層では 1字が平均 2.59語義 を背負い、語義接地率 56.9%。
    字を分割したのは全語根の 1.30%(第15レンズ)だけ。
    ユーザー原則の「可能な限り解釈を頑張って字種を増やさない」は、
    大規模に、かつ**同一語の意味拡張に限って**適用されている。
  ・原則の但し書き「全く意味が異なる場合は新たな割り当ても致し方ない」に該当する
    取りこぼし（別語源の同綴異義で1字にまとめてしまっているもの）は**新規ゼロ**。
    既知のものは全て台帳と§14.2.1に載っており、機構が自動で除外する。
  ・上位層ほど多義が重い(2.40 vs 2.20語義/語根)にもかかわらず接地率は同水準で、
    最優先層は相対的に良く効いている。

  角を矯めた箇所: なし。データ変更ゼロ。
