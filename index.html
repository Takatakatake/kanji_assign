1全体像：この道具群は何をするものか

中心にあるのは「エスペラント語根に漢字を割り当てる辞書」です。この辞書をもとに、漢字化文を書く、普通のエスペラント文を一括変換する、漢字化文を元に戻す、学習・音声・会話字幕へ広げる、という流れができます。

4-1. エスペラント語根漢字割当表kanji_assign / kanji.html

辞書・基盤データ

語根にどの漢字が割り当てられているかを確認するビュー。プロジェクト全体の対応表です。

入力検索語（語根・漢字・識別子・語義）
出力該当する語根、漢字、識別子、区分、頻度、画数、語義

向いている用途: 漢字化文を書く前の確認、識別子の確認、辞書メンテナンス。

具体的にできること

  • 語根、漢字、識別子、語義で検索できる。
  • basic / pejvo / piv / prep / suf / pref / correl などの区分で絞り込める。
  • 同じ漢字を共有する語根グループを確認できる。
  • 識別子付きだけを表示できる。例: 出ᴱᴷ、穿ᴾ、在ᶜ̂。
割当表を開く（kanji.html） 複合語ビュー（words.html） GitHub
書

4-2. 漢字化エスペラント入力エディタkanji-esperanto-monaco

入力・執筆

Monaco Editor上で、エスペラント語根を入力すると漢字化候補を出すWebエディタです。

入力エスペラント語根・文
出力漢字化エスペラント文

向いている用途: 日記・投稿文・例文などを、手入力で丁寧に漢字化したいとき。

具体的にできること

  • bon と打つと 良 のように、語根から漢字候補を選べる。
  • 候補には識別子付き漢字も含められる。
  • 割当検索パネルで、ある漢字に対応する語根を逆引きできる。
  • コピー、ペースト、全選択、共有、ローカル保存、履歴復元に対応。
  • 一度オンラインで開いた後のオフライン利用も考慮されている。
エディタを開く GitHub
変

4-3. 日中韓注釈ルビ・漢字化ツールesperanto-radiko-cjk-annotator

自動変換・読解補助

普通のエスペラント文を語根分解し、日本語・中国語・韓国語の注釈ルビ、漢字化ルビ、タグなし漢字化文に変換します。

入力普通のエスペラント文、またはテキストファイル
出力ルビHTML、編集可能HTML、タグなし漢字化文、ダウンロードファイル

向いている用途: 長めの文を一括でルビ化・漢字化したいとき。読解支援や投稿用変換に向いています。

具体的にできること

  • 注釈ルビ: 語根の上に日中韓訳を表示。
  • 漢字化ルビ: 漢字を本文、エスペラント語根をルビにする。
  • 純粋置換: HTMLタグなしの漢字化テキストを出す。
  • 手動入力・テキストファイルアップロードに対応。
  • %...% は変換しない、@...@ だけ変換する、といった部分指定ができる。
  • 誤った語根分解をGUIで補正し、user_corrections.jsonとして保存・復元できる。
日本語版を開く 中文版 한국어판 GitHub
戻

4-4. 漢字化エスペラント逆変換器kanjized-esperanto-reverter

検証・復元

漢字化エスペラント文を、小文字のアルファベット表記へ戻すツールです。

入力漢字化エスペラント文
出力小文字アルファベット表記のエスペラント文（語根・語尾・記号を含む）

向いている用途: 漢字化文の検証、元文復元、変換規則のテスト。語根区切りがないため、複合語では曖昧性が残る場合があります。

具体的にできること

  • PEJVO/PIV 2026-06-20版、スニペット用2列CSV、カスタムCSVを切り替えられる。
  • 上付き識別子を含む漢字表記を認識できる。
  • 漢字とアルファベットが混在した文にも対応。
  • 変換結果をテキストとしてダウンロードできる。
逆変換器を開く GitHub
学

4-5. エスペラント4択学習アプリesperanto_quiz

学習・練習

日中韓対応の単語・例文4択クイズです。PC版とスマホ版があり、音声・スコア・ランキングにも対応します。

入力クイズ設定、回答選択
出力正誤、得点、復習、ランキング

向いている用途: 語彙・例文を反復学習したいとき。スマホで毎日練習する用途に強いです。

具体的にできること

  • 単語クイズ: 2890重要語彙を品詞・レベル・グループ別に出題。
  • 例文クイズ: Topic / Subtopic / Levelを選んで出題。
  • 出題方向は「エスペラント→訳語」「訳語→エスペラント」。
  • 間違えた問題だけを正解まで出すスパルタモードがある。
  • 音声再生、Google Sheetsランキング、スマホ用localStorage保存型UIに対応。
  • 日本語版・中国語版・韓国語版で訳語列を切り替える。
日本語版を開く 中文版 한국어판 GitHub
声

4-6. エスペラント音声合成paroligu

音声教材作成

エスペラント文をRHVoiceのSpomenka音声で読み上げ、WAVまたはMP3として保存できます。

入力エスペラント文、音声設定、保存ファイル名
出力ブラウザ再生音声、WAV、MP3

向いている用途: 例文読み上げ、発音確認、学習用音声ファイル作成。

具体的にできること

  • Unicode表記とx記法の両方に対応。
  • 速度・高さ・音量を調整できる。
  • MP3ビットレートを選べる。
  • ブラウザで再生し、WAV/MP3で保存できる。
  • Streamlit Cloud上でもRHVoiceを使えるよう、必要パッケージを起動時に展開する設計。
paroligu を開く GitHub
幕

4-7. エスペラント音声リアルタイム文字起こしUbuntu版 / Windows版

会話・会議字幕

ZoomやGoogle Meetのエスペラント会話をリアルタイムに文字起こしし、日本語・韓国語翻訳、Zoom字幕、Web字幕ボード、Discord投稿へ流せるローカルツールです。

入力マイクまたはPC音声ループバック、APIキー、Zoom CC URL、翻訳設定
出力文字起こし、翻訳、Zoom字幕、Web字幕ボード、ログ、Discord投稿

向いている用途: オンライン授業、会議、発表、エスペラント会話の記録。Streamlit CloudではなくローカルPCで動かすツールです。

具体的にできること

  • Speechmatics Realtime STTを中心に、VoskやWhisperをバックアップとして使える。
  • Zoom Closed Caption APIへ字幕を送れる。
  • Web UIで最新字幕と履歴を表示できる。
  • 日本語・韓国語などへの翻訳表示に対応。
  • Discord Webhookで確定文と翻訳をまとめて投稿できる。
  • Ubuntu版はPipeWire/PulseAudioのループバック補助、Windows版はVB-Audio/VoiceMeeter等を前提に診断・設定支援がある。
Ubuntu版リポジトリ Windows版リポジトリ ローカル実行（Streamlit Cloudなし）

5おすすめの使い分け

目的おすすめの流れ
漢字化文を一括で作る普通のエスペラント文を用意 → CJK Annotatorで「純粋置換」または「漢字ルビ」を選ぶ。
細部まで手で調整するkanji_assignで割当を確認しながら、Monaco入力エディタで語根ごとに候補を選ぶ。
識別子が正しいか確認するkanji_assignで同字グループと識別子を確認し、必要ならMonacoやAnnotatorの結果を修正する。
漢字化文を検証するReverterで小文字エスペラントへ戻し、意図しない語根に戻っていないか確認する。
学習教材を作るQuizで語彙・例文練習、paroliguで例文音声を作る。
会議・授業で使うUbuntu/Windows文字起こしツールをローカルで起動し、Web字幕・翻訳・Zoom字幕へ流す。
