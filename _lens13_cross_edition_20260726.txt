==========================================================================================
第13の検証レンズ: 版間整合性 —— 学習者版と学術版で同じ語が別の字になっていないか (2026-07-26 第27回続34)
==========================================================================================

これまでの12レンズは全て【片方の版】または【語根台帳】の中だけを見ていた。
本レンズは初めて **両版を突き合わせる**。両版は分解の粒度が設計上ちがう
(学習者版=補助分解を積極展開 / 学術版=PEJVO設計を尊重)ので粒度差そのものは正常であり、
問題になるのは (A)片方だけ漢字化されている=被覆の非対称 (B)両方漢字だが裸字の並びが違う の2つ。
さらに、正本が自ら **##偽分解(衝突語)** と印を付けた行(=綴りの偶然でそう切れただけと正本が宣言
している行)を悉皆で棚卸しした。ここは原理的に偽の友が生じやすいのに、一度も全件監査していなかった。

[13-2] §3.1『分解鏡像』の版間検算 —— 96.6% で鏡像が完全一致
------------------------------------------------------------------------------------------

  §3.1 は「未分解の合成語根には成分の固定字を連結して割り当てる」という規約。
  これが効いているなら、学術版が1語根で持つ熟語(例 kilogram=千克)と
  学習者版がその語を分解して並べた字(千+克)は一致するはずである。

    対象(学術版=多字熟語1語根 / 学習者版=2分節以上) = 1,870語
      ★完全に鏡像が一致 = 1,806 (96.6%)
       部分一致(包含)   =    24 ( 1.3%)
       不一致           =    40 ( 2.1%)  ← 本レンズの是正でこの類が45→40に減少

  ⇒ 規約は机上の建前でなく、実データで96.6%成立していることを版間で独立に確認できた。

[13-3] 『学術版のみラテン』586件の内訳 —— 構造的な隙間で、狙って埋める旨味は無い
------------------------------------------------------------------------------------------

    全分節が未登録            = 584件 (CSV2890 0 / PEJVO 158 / PIV 426)
    意図的ラテン(既裁定)      =   2件 (agami/a=無性の・nau^t/o=【楽】9音程)

  584件は「学術版が結合形を未分解のまま持ち、その結合形が語根として未登録」型。
  原因となる結合形を頻度順に並べても最大3語(stenotip/fenil/kinematograf/eu^femism…)しか
  巻き込まない長い裾で、まとめて効く穴は存在しない。**CSV2890層は0件**ゆえ優先度も低い。

  この42行を3バッチに分け、多エージェントで判定 → 各主張を **3つの独立レンズ**
  (①中国語話者が語釈を復元できるか ②語源 ③既存裁定との整合)で敵対検証し多数決。

[13-5] ★実装上の落とし穴を1つ発見して是正: elseif チェーンの順序による dead code
------------------------------------------------------------------------------------------

  鉱物-ite の語釈scoped規則を最初 $chemSaltLine / $medIt の分岐より **後ろ** に置いたところ、
  klor は $chemAcid に・nefr と kord は $medStem に登録済みのため上流の分岐で先に食われ、
  規則が書かれているのに1行も発火しない dead code になっていた(合成エージェントが指摘)。
  → 分岐を $chemSaltLine より前へ移動し、コメントに「必ず前に置くこと」と理由を明記した。
  同種の事故を防ぐため、以後この種の語釈scoped規則は【上流の一般規則より前】に置く。
