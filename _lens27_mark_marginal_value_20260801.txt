■ ★最初に: 本レンズの初版は5方向の独立検証で全面的に覆された

  第25レンズの批判[C5](識別子は家族ローカルに再利用される=ᴴ が hidr/hermini/higien)を
  受けて「識別子アルファベットの体系性」を測る初版を書いた。5エージェントの敵対的検証
  (バグ狩り2・反証2・設計批判1、実データ照合つき)にかけた結果、主要4主張はいずれも成立しなかった。

  【虚偽だった主張】
   ★D節「識別子空間の近傍は第23レンズの原理的死角で、本節が初」= **事実として虚偽**。
     第23は `_lens23_near_collision.py:168` で識別子付き面 surf_full を実際に構成し
     :288 で類型1の判定に使っている(曖昧10,193件30.5%→320件0.96%の数字はそれ)。
     さらに第23の【初版】は識別子込みの編集距離で第27-D型を1,640対すでに検出し、
     報告書 line51-54 で「識別子は内容文字ではなく曖昧性解消の付加情報なので、距離は
     識別子を外した漢字列で測り識別子は属性として扱うのが正しい」と明文で棄却していた。
     つまり第27-Dは「死角の発見」ではなく **「棄却済みモデルの無断復活」** だった。
   ★同じD節の中身も同語反復だった。被害語根1,635件の **100.0%** が「id先頭字が家族内で
     衝突するから多字idになった」語根で、末尾を落として衝突相手に戻るのは生成規則の定義そのもの。
   ★実害も理論値だった。F重みでは32.6%→**3.1%**、被害語根の79.0%がF≤1。実配信テキスト
     (漢字9,743字)で末尾落としが成立しうるのは25回=**漢字390字に1回**、同テキストで識別子層が
     解消している曖昧イベント6,152回に対し **収支246:1の黒字**。
   ★近傍モデル自体も恣意的だった。同じ距離1の「置換」方向(13,263対/3,506語根)を数えておらず、
     一貫させれば32.6%ではなく77.9%になる=32.6%は近傍の大きさを表す数字ですらない。

  【交絡だった主張】
   ★C節「逆引き成功率が層順に単調(84.6/76.6/72.8/50.2)=優先順位が識別子の学習性に効く」
     = **群サイズの完全な交絡**。層別の平均群サイズは 4.10/7.61/30.23/124.58 で、
     群サイズ分布に直接標準化すると 82.5/**62.9**/**64.2**/**65.0**% と下位3層が逆転(PIVが最良)。
     Mantel-Haenszel調整ORは3組すべて1未満に反転。F加重では 70.7/75.1/75.6/57.6% で
     文法層が3位に落ちる。指標自体が「家族内の同頭文字競合数」のほぼ決定論的関数で
     (id長=1の2,678件で 成功⟺競合数=1 が反例0)、層は個体レベルで情報量ゼロ(層だけの予測=64.9%
     =「常に成功」の基準線と同値)。加えて上位3層の差は統計的に有意ですらない(文法層 n=39)。
   ★機構的にはむしろ逆だった。`_gas_identifier.ps1` は同頭文字群を優先順位で並べ、
     **最も優先順位が高い非基本形に裸の頭文字idを与える**(L56)。裸の頭文字idは必ず
     同頭文字メンバー全員と適合するので逆引きに失敗する。同一頭文字群の直接対決では
     CSV2890 は PEJVO に 4勝87敗。

  【失敗し得ない検定だった主張】
   ★A節「規則外0.0%」= 生成器の仕様の言い換え。`_gas_identifier.ps1` が出力し得るidは
     ''/頭文字/頭文字+1字/漸進接頭辞 だけで、規則外は構文的に生成不能。
     生成器に忠実に分類し直すと 頭のみ53.4% / 頭+後続子音37.8% / 頭+後続母音6.3% /
     漸進接頭辞2.5% = **100%が規則内**(初版の「80.2%」は分類器の粗さが生んだ過小報告)。
   ★A節「層別のid長(1.21/1.19/1.40/1.75)」= **第8レンズと同一事実**(第8の分布から誤差ゼロで
     復元できる)。しかも第8は本文で「識別子の長さは§9契約により語根の綴りで決まるので
     層順とは無関係。層順が支配すべきは『群の無印を誰が持つか』の一点」と **測る意味がないと
     裁定済み** だった。家族サイズで標準化すると 1.19/1.34/1.44 と差の半分が消える。
   ★E節「鏡像15件は群サイズ1=体系に干渉なし」= 上付きを含むgroupkeyは他に存在しないため
     衝突が定義上不可能な **空振り検定**。反証可能な検定(下記3節)に置き換えたら2件が衝突した。
   ★D節「家族内id完全重複=0」= 既存の恒久監査 [A]⑤ の再掲。

  【初版が実際に踏んだ測定バグ】
   ・表記系の片側正規化(`ĉe` の id `ĉ`)で173件が丸ごと「規則外」に誤分類 → v2で是正済み。
     ★これは [[reference-audit-encoding-mixture]] に記録済みの既知トラップに自分で嵌まったもの。
   ・cons抽出が ŭ(h-system `u^`)を破壊し127件の子音列が誤り(生成器は ŭ を子音扱い)。
   ・接頭辞判定を生文字で行い、結合ダイアクリティカルだけが違う対37件を混入。
   ・tier判定が学習者版のみから作られ、band=basic の32語根がPEJVOに誤配。
   ・層別集計が「対」単位、率が「語根」単位で単位混在(1,794対 vs 1,635語根)。

■ 差し替えた測定: 「マークの限界価値」
--------------------------------------------------------------------------------

  独立検証が唯一「学習者モデルに依存しない量」として提案した指標を実装した。
  ★問い: **マークを一切読まない読者にとって、その層はどれだけ読めるか**
  = 漢字描画された内容分節の【延べ出現】のうち、マーク付き描画の割合。
  マークを落とせば必ず家族の基本形に着地するので、この率がそのまま「マークへの依存度」になる。
  丸暗記読者でも規則読者でも同じ意味を持つ(初版C節の弱点=モデル依存を回避)。
  第8レンズは【型】レベルの無印率を測っており、分母が違う。

    [学習者版] 漢字描画された内容分節
      層          延べ出現    マーク付き   マーク率
      文法層        30,512     2,216      7.3%
      CSV2890     48,830    11,048     22.6%
      PEJVO       15,485     8,717     56.3%
      PIV          3,621     2,645     73.0%
      全体         98,448    24,626     25.0%

    [学術版] 文法層 3.3% / CSV2890 21.6% / PEJVO 53.9% / PIV 45.6% / 全体 22.2%

  ★学習者版では層順に完全単調。最優先層は延べ出現の77.4%が無印=**マークを一切読まなくても
    ほぼ読める**。PIVは73.0%がマーク付きで、識別子機構なしには成立しない層。
  ・開示1: 学術版はPIVで単調性が崩れる(45.6% < PEJVO 53.9%)。whole-root融合により
    PIV項目が1トークンの無印描画になる割合が高いため。版の設計差であって欠陥ではない。
  ・開示2: この結果の相当部分は「最優先層が無印を取る」設計(第25レンズが91.7%と実測)と
    「上位層ほど家族が小さい」構造(第8レンズ)の帰結である。本レンズの新規性は
    **延べ出現重みで測ったこと**と、その大きさ(7.3% vs 73.0%=10倍差)を実データで示したこと。
  ・実配信テキスト(ユーザー自身の漢字化エスペラント2集): 本文の漢字9,289字のうち
    マーク付きは**1,044字(11.2%)**、うちマークが2単位以上は169字(1.82%)。
    頻出は 和ᴷ×286 事ᴬ×56 期ᴰᴹ×40 因ᴾ×31。実文の約9割はマークを読まなくても字だけで読める。
    ★2026-08-01(続64)是正: 初出時は1,008字(10.9%)/159字(1.71%)と報告したが、本節だけ
      文字クラス [ʰ-˿ᴬ-ᵪ̀-ͯ⁰-₟] でマークを判定しており **ᶜ(U+1D9C)・ᶠ(U+1DA0)・ⱽ(U+2C7D)が
      範囲外で36件取りこぼれていた**(在ᶜ×10 商ᶠ×6 值ⱽ×4 …)。本ファイル冒頭の is_mark
      (Unicodeカテゴリ Lm/Mn/Sk)と同一規範に統一して再計測した。
      ★1節の層別マーク率(7.3/22.6/56.3/73.0%)は元から is_mark を使っており**影響なし**。

■ 反証可能な検定に置き換えたE節: 続62の鏡像15件
--------------------------------------------------------------------------------

  初版は「群サイズ1」を見ただけだったが、上付きを含むgroupkeyは他に存在しないので
  衝突は定義上起こり得ず、何も検定していなかった(空振り)。
  正しい検定=「上付きを全部剥がした面が全域(家族外を含む)で一意か」で測り直すと:

    ★endoskopi(内ᴱᴰ镜ˢᴷ) → 剥離面 内镜 は endoskop と衝突
    ★mikroskopi(微镜ˢᴷ)  → 剥離面 微镜 は mikroskop と衝突
    残り13件は全域一意。

  ・評価: 衝突する2件も着地先は同義隣接(手技 vs 器具)で実害は薄い。またこれは
    「マークを完全に無視する」読み方であり、全マーク付き語根5,015件に共通の構造的性質で、
    続62が新たに作った欠陥ではない。**ただし初版E節が「干渉なし」と断じたのは誤りだった。**
  ・なお [J] 表面同形検査(続60で恒久化)は上付きを剥がさないキーで比較するので、
    この2件は検出対象外である。上付き剥離キーまで監査に足すべきかは設計判断
    (足すと全マーク付き語根が「衝突」になるため、監査としては無意味になる)。

■ 結論
--------------------------------------------------------------------------------

  ・優先順位はマークへの依存度にも現れている: 最優先層は延べ出現の**77.4%が無印**で、
    マークを一切読まない読者でもほぼ正しく読める。PIVは73.0%がマーク付きで機構依存。
    実配信テキストでもマーク付きは漢字の10.9%にとどまる。
  ・ただしこれは第25(無印は最小層が持つ)と第8(上位層ほど家族が小さい)の帰結を
    延べ出現重みで測り直したものであり、**独立の新事実ではない**。
  ・★初版の主要4主張(第23の死角/層順単調/規則外0%/鏡像干渉なし)は全て覆った。
    とりわけ「第23レンズの死角」は事実として虚偽で、第23が理由付きで棄却したモデルの
    無断復活だった。この誤りを記録に残す。
  ・是正: 0件。データ変更: 0件(読み取りのみ)。角を矯めた箇所: なし。
  ★自己バグの7例目(第21×2・22×2・23×3・24×7・25×2・26×7・27)。今回は特に、
    **既存レンズの報告書を読まずに「初めて測る」と主張した**のが最大の失敗だった。
    今後、新レンズを立てるときは必ず先に該当する既存レンズの本文を読むこと。
